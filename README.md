# Fantasy ETF League 📈🏆

Welcome to your Fantasy ETF League project! This website will allow you and your 3 friends to compete in a stock market game by creating custom baskets of ETFs.

## How it Works
1. **Baskets**: Each player selects a basket of ETFs.
2. **Daily Updates**: Every weekday at 4:00 PM EST (market close), the app fetches the latest prices for these ETFs.
3. **Scoreboard**: The app displays the rankings, total returns, and basket compositions for each player.
